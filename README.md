# Strategic Fretboard Website

A lightweight, responsive promotional website for the Strategic Fretboard iPhone and iPad app.

## Pages

- `index.html`: App overview, screenshots, features, and store links
- `privacy.html`: App and website privacy information

## Publishing

Upload the contents of this folder to the root of the Strategic Fretboard GitHub repository. The App Store button is active. Google Play is intentionally displayed as “Coming soon” and is not clickable.
